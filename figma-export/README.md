# THE90 → Figma

Перенос прототипа в редактируемый макет Figma. Не часть приложения — только инструмент.

Работает так: скрипт обходит живой DOM прототипа, снимает **использованные** значения
(`getComputedStyle` + `getBoundingClientRect`) и пишет сцену в JSON. Плагин Figma
собирает по этому JSON настоящие слои — auto-layout там, где во вёрстке flex,
переменные для токенов, текстовые стили, компоненты для повторяющихся блоков.

Итог: **43 экрана и состояния**, ~8 200 узлов, ~2 900 auto-layout контейнеров,
58 переменных, 56 текстовых стилей, 40 компонентов на 365 инстансов.

---

## Как собрать макет

### 1. Поднять прототип

```bash
node .claude/serve.mjs
```

Сервер отдаёт прототип на `http://localhost:4173` и принимает выгрузку в `figma-export/`.
Он должен работать и во время шага 3 — плагин тянет оттуда картинки.

### 2. Снять экраны (нужно только если прототип изменился)

Открыть `http://localhost:4173`, DevTools → Console, вставить содержимое
[`run-in-console.js`](run-in-console.js). Вкладка должна оставаться активной.

Затем:

```bash
node figma-export/build.mjs
```

Этот шаг делает четыре вещи:

| шаг | что делает |
|---|---|
| `verify.mjs --fix` | заново считает auto-layout по правилам Figma и сверяет с браузером; всё, что не сходится, возвращает к измеренному размеру |
| `components.mjs` | находит блоки, повторяющиеся ≥ 4 раз, и помечает их как компоненты |
| `simulate.mjs` | прогоняет `plugin/code.js` на подставном Figma API — ловит нарушения ограничений до того, как их поймает Figma |
| `render.mjs` | рисует результат в `preview.html`, чтобы можно было посмотреть глазами |

Сейчас расхождений геометрии — **0 из 4 948** вычисляемых осей.

### 3. Запустить плагин в Figma

1. Figma → **Plugins → Development → Import plugin from manifest…**
   → выбрать `figma-export/plugin/manifest.json`
2. Открыть файл THE90, перейти **на страницу «From prototype»** — плагин строит
   на текущей странице.
3. **Plugins → Development → THE90 → Figma**, нажать **Build the design**.

Сборка занимает несколько минут (43 экрана, ~130 картинок). Прогресс и заметки
показываются в окне плагина.

Повторный запуск строит заново — сначала удалите старое содержимое страницы.

## Что получается на странице

| доска | содержимое |
|---|---|
| `00 · Foundations` | палитра и типографическая шкала как живая спецификация |
| `01 · Onboarding` | welcome, sign in, create, profile, teams |
| `02 · Home & Live` | main, live match, rankings, ranks |
| `03 · Leagues` | лига, создание, участники, раунды, чат |
| `04 · Arena` | арена и турнир |
| `05 · My Zone` | профиль, уведомления, инвайты, саппорт |
| `06 · Settings` | настройки и их подэкраны |
| `07 · Overlays` | модалки и bottom-sheet поверх своего контекста |
| `08 · Components` | 40 компонентов, на которые ссылаются инстансы |

Каждый экран — фрейм 390 × 852 с фоном, статус-баром, самим экраном и таб-баром
в том же порядке отрисовки, что и в вёрстке.

### Что внутри фрейма

- **Auto-layout** там, где в CSS был flex/grid с ровными отступами. Неровный
  отступ (то есть `margin` на одном из детей) разбивается на вложенные группы —
  так, как это собрал бы дизайнер руками.
- **Имена слоёв** — из классов вёрстки: `picksbar__progress`, `nav · active`.
  Суффикс `· active` — это состояние, `· spacer` — невидимая распорка, которая
  держит место в строке.
- **Переменные** `THE90`: `color/brand/primary`, `color/text/muted`, `size/…`.
  Токены из `:root` названы по-человечески, остальные цвета — `color/palette/HEX`.
- **Текстовые стили** — `Sora/SemiBold/14 · 20` и т. п., на все связки,
  встречающиеся ≥ 5 раз.
- **Компоненты** — только точные повторы (та же структура, те же заливки, тот же
  текст), поэтому ни одному инстансу не нужны оверрайды.
- **Скролл** — контейнеры со скроллом получают `overflowDirection`; содержимое
  целиком лежит внутри, снимите clip на фрейме экрана, чтобы увидеть всё.

## Известные упрощения

- **Ховеры, фокус, disabled** не сняты — прототип отдаёт покой, а не наведение.
  Если нужны состояния кнопок, их проще дособрать в Figma.
- **Шрифт**: `Sora Black` (900) в Figma нет — падает на `ExtraBold` (800).
  Системный шрифт статус-бара заменён на `Inter`.
- **Анимации** остановлены на первом кадре: карусели стоят на первом слайде,
  таймеры не идут.
- **Табы турнира** — это одна горизонтальная лента со всеми панелями подряд,
  как во вёрстке; экран её обрезает. Табы лиг сняты отдельными состояниями,
  потому что там панели действительно переключаются.
- **Текст** хагает по своей ширине, а не пришпилен к измеренной: метрики Sora
  в Figma и в Chrome могут разойтись на доли пикселя. Рамки вокруг текста
  плагин при расхождении > 1.5 px возвращает к измеренному размеру.

## Файлы

```
extract.js          обходит DOM, собирает сцену        (грузится в страницу)
drive.js            водит прототип по экранам          (грузится в страницу)
run-in-console.js   то, что вставлять в консоль
build.mjs           весь пост-процесс одной командой
verify.mjs          движок auto-layout + сверка (--fix пришпиливает)
components.mjs      поиск повторов
simulate.mjs        подставной Figma API + прогон плагина
render.mjs          preview.html
screens/*.json      сцены
tokens.json         CSS-переменные
assets.json         иконки (инлайн SVG) и пути к картинкам
index.json          список экранов
plugin/             manifest.json · code.js · ui.html
```
