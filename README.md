# THE90 — Web prototype

Прототип мобильного приложения в мокапе iPhone. Дизайн вытянут из Figma —
[THE90](https://www.figma.com/design/tRsbWlaKqdN79pzboa322G/THE90?node-id=515-2151),
секции **SIGN IN**, **MAIN** и **MY ZONE** (фреймы `Main – Full Scroll`,
`Main – Accepted cards`, `PopUp`, `My Zone – Profile`).

## Запуск

Статика, сборка не нужна:

```bash
cd /Users/jackmilka/Desktop/THE90 && python3 -m http.server 8777
```

Открыть `http://localhost:8777`.

## Структура

```
index.html            страница: чёрный фон, логотип, мокап iPhone с экранами
css/style.css         токены дизайна, экраны регистрации
css/main.css          главный экран, карточки, календарь, модалка
css/my-zone.css       профиль My Zone, достижения, история, темы
js/app.js             подгонка мокапа под экран, навигация, валидация полей
js/data.js            клубы, генерация матчей, календарь, модель очков
js/main.js            логика главного экрана
js/my-zone.js         выбор темы и поведение верхней панели при скролле
assets/
  the90-logo.svg      логотип проекта (над мокапом)
  clubs/              8 клубов: логотип + «флаг» для размытого фона карточки
  img/                hero, баннер AD, аватар, награда TOP-1
  icons/              иконки из Figma
  my-zone/            точные Figma-экспорты профиля, наград и тем
THE90.svg             исходный логотип
```

Мокап iPhone — чистый CSS (рамка, кнопки, Dynamic Island), экран ровно 390×852 px,
как фрейм в Figma. Масштаб под окно считается в `fitDevice()` в `js/app.js`.

## Экраны

| Экран | Что делает |
|---|---|
| `welcome` | Hero-фон, слайдер-точки, вход в регистрацию |
| `signin` | Вход: email + пароль |
| `create` | Регистрация: email, пароль, подтверждение, чекбоксы |
| `main` | Главный экран: LIVE, 10 Daily picks, AD, календарь |
| `my-zone` | Профиль: статистика, достижения, фавориты, история и темы |

Переходы — по ссылкам внутри макета (`Create Account`, `Sign In`, `Create Account Now`).
После регистрации сразу открывается главный экран и модалка с наградой за вход.
Нижняя навигация переводит из `Main` в `My Zone` и обратно; выбранную тему можно
переключить между `Dark night` и `White light`.

## Главный экран

- **top-app-bar** фиксирован, контент уезжает под затемнение и статус-бар мокапа.
- **LIVE** над Daily picks: точка мигает, минута матча тикает.
- **10 карточек** на 8 клубов из Figma (логотип + размытый «флаг» клуба на фоне).
  По умолчанию не выбрано ничего, плашки Accept не видно.
- **Календарь**: горизонтальный скролл дней, `Today` всегда зелёный, выбранный день —
  подсветка + обводка. Сегодняшний список совпадает с Daily picks, остальные дни —
  свои 10 матчей (детерминированно от даты).

### Как заполняется карточка

| Действие | Что происходит |
|---|---|
| Счёт `1:0` | автоматом `Win 1` |
| Счёт `1:1` | автоматом `Draw` + `Both to score: Yes` |
| `Both to score: No` | автоматом счёт `0:0` + `Draw` |
| `Both to score: Yes` | не заполняет ничего |
| Исход руками | если противоречит введённому счёту — счёт сбрасывается |

Счёт — необязательное поле, по умолчанию `-` `-`; вводится клавиатурой или `+` / `-`.

### Accept

Плашка выезжает над нижним меню после первого выбора. Кнопка `Accept` заблокирована,
счётчик показывает `N/10`. На `10/10` кнопка активна и счётчик пропадает. После
подтверждения — модалка (фрейм `PopUp`), карточки сворачиваются, видно 3 из 10 плюс
`Watch all picks`, баланс растёт на сумму прогноза.

### Редактирование

Клик по свёрнутой карточке раскрывает прогноз: на `Win / Draw / Win 2` показан процент
других игроков. Кнопка `Edit` внизу возвращает карточку в редактируемый вид — проценты
пропадают, плашка возвращается с суммой всего купона (с учётом правки) и кнопкой
`Accept` уже без счётчика. Повторное подтверждение модалку не показывает.

## Статусы полей

Логика в `js/app.js`, стили — `.field` в `css/style.css`.

| Статус | Класс | Фон | Бордер | Текст |
|---|---|---|---|---|
| Default | — | `#1A1A1A` | `rgba(255,255,255,.1)` | `#6E7F76` (placeholder) |
| Active (в фокусе) | `.is-active` | `#272727` | `rgba(255,255,255,.28)` | `#F7FAF8` |
| Valid | `.is-valid` | `#13231A` | `#1FCB72` | `#F7FAF8` |
| Error | `.is-error` | `#261414` | `#F05D5D` | `#FF9D9D` |

Поведение:

- фокус → `active`;
- ввод → поле подсвечивается зелёным сразу, как только значение стало валидным; ошибка при вводе не показывается, пока поле «чистое»;
- blur → проверка, при провале — `error` + подпись под полем;
- submit → проверяются все поля, пустые считаются ошибкой, поле трясётся;
- пароль на регистрации: 8+ символов, буквы, цифры и спецсимвол;
- подтверждение пароля пересчитывается при изменении основного пароля.

## Математика очков

Всё в `js/data.js`. Для каждого матча строится одна модель Пуассона от силы команд
(с домашним преимуществом ×1.18), из неё выводятся **все** рынки — 1X2, точный счёт
и both-to-score. Поэтому числа согласованы между собой, как в реальной линии.

```
odds = (1 / probability) × 0.92        // 8% маржи
```

Очки за прогноз: `outcome = odds × 50`, `точный счёт = odds × 15` (потолок 900),
`both to score = odds × 25`. Один исход даёт примерно +100…+250 — тот же порядок,
что и `+150` в макете. Полный купон из 10 карточек — около +1 500…+2 500.

Проценты «сколько людей выбрали этот исход» берутся из тех же вероятностей модели,
смещённых стабильным псевдослучайным biasом (ничьи публика недобирает), и всегда
дают ровно 100%.
